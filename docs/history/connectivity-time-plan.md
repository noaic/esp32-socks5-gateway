# 提案：互联网状态、灯色与时间同步

2026-10-05。历史提案；最新决定为 NTP 暂缓，手动与低频自动检查已按 web48 实现，见 [实现与验证](web48.md)。以下默认手动、备用目标及授时部分不代表最终实现。

原提案：此提案响应新的互联网检查需求，不把此前“暂不增加周期公网探测”视为已经取消：第一版默认手动检查，自动检查另设可关闭的选项。

## 优先实现：互联网状态与灯色

现有手动诊断只验证SOCKS端口、NO AUTH和通过UDP ASSOCIATE取得DNS回复，不能仅凭这三项宣布HTTP业务可达。建议在保持该分阶段信息的基础上增加经SOCKS的HTTP连通性验证。

流程：通过当前配置DNS和SOCKS UDP ASSOCIATE查询检测域名的A记录，解析IPv4结果；再使用SOCKS CONNECT到该IPv4并发起小型HTTP请求，验证预期状态码/响应。保留IPv4和NO AUTH，不增加domain ATYP或HTTP代理协议；HTTP只是诊断请求。目标由用户可见且可修改，不探测VPS管理入口，不添加直连绕过代理的成功兜底。

第一版可用预期204/短正文的HTTP端点，避免为检测单独增加TLS/证书/授时依赖。DNS成功、CONNECT成功或任意字节响应均不足以单独判定成功。结果表示“最近该检测路径通过”，不能保证所有网站、QUIC或每台客户端均可用，也不是对远端身份的加密认证。

状态分为未检查/检查中、最近通过、连续失败、已过期；Web显示最近结果、目标、失败阶段、耗时及距成功多久。AP/STA断开、SOCKS/DNS配置变化及代理重建后证据失效；检查开始与结束需核对网络代次，避免断网后旧结果重新点亮绿灯。限时、串行、固定缓冲，复用现有维护worker，不新增逐连接任务。

灯色建议（关闭设置仍最高优先级）：

- 蓝：上游未配置，本地AP供配置。
- 红：上游已配置但STA未就绪。
- 紫：AP+STA就绪，互联网状态未知/检查中/已过期。
- 绿：AP+STA就绪，最近一次通过代理的互联网检查成功且未过期。
- 黄：网段冲突，或重复检测确认失败；Web区别显示原因。单次失败先回到紫色，不立刻宣布整个互联网故障。
- 关闭：沿用当前持久开关。

绿灯建议有效期10分钟，依赖单调时钟，不依赖NTP。关闭自动检测后，可手动重新验证；成功过期则转紫色。

可选自动模式：STA取得IP后检查一次，正常每5分钟检查；失败按30/60/120秒等退避至5分钟。仅在网络就绪时运行，不与手动维护重叠；手动操作优先。不采用每秒ping，不因失败自动重启或重建所有业务连接。固定一个主目标，主目标失败时可用备用目标降低单点误判，严格限制总期限；目标选择和失败阈值需要实现前确认。

## 其次考虑：ESP32自身SNTP授时

当前超时、回滚、事件顺序依赖单调时间，转发无需正确墙钟。授时收益是显示实际日期、便于对齐ESP32和Xray日志；不应成为上网、登录或绿灯前置条件。这里是ESP32向时间服务器同步，不实现本地NTP服务器或自动给AP客户端提供NTP。

本机IDF6.1已核对esp_netif_sntp_init/start与sync_cb接口及lwIP SNTP实现；官方实现使用lwIP UDP/定时器，不需要新建独立FreeRTOS任务。初始化一次，STA有IP后启动，可关闭，低频同步。服务器配置须明确；上游路由器支持NTP不能预先假定。

重要路径差异：当前透明hook只处理AP客户端输入；原生SNTP自己的UDP socket会按STA路由发送，并不会自动走SOCKS。若允许ESP32管理流量经STA直连，可使用官方SNTP，Web说明该路径。若希望授时也必须经过SOCKS，则需额外集成UDP association与SNTP接收/校时，复杂度更高，建议先暂缓而非悄悄直连。

时间状态显示未同步、最近同步时间和服务器；授时失败不阻塞启动。事件始终保留单调时间，墙钟跳变不能改变流超时/回滚期限；未同步的旧事件不能伪装成精确日期。时区属于展示设置，协议时间保持UTC。

## 推荐顺序与验证

1. 网络检查状态、手动HTTP检查、紫/绿灯语义，默认无周期外部请求。
2. 可选低频自动检查、过期和失败退避；测后台流量、内部RAM、维护响应及误判。
3. 明确授时路径后增加可选SNTP和日期显示，失败仍可正常代理。
4. 重复错误日志合并、日常稳定性观察；串口恢复继续低优先级，BLE/OTA暂不加入。

资源评估以内部RAM为主：新增状态和灯色很小，DNS/HTTP检查要少量临时socket和缓冲，HTTPS将增加TLS临时内存。具体峰值需构建与板测，不能先承诺零开销。检查覆盖成功、SOCKS不可达、DNS失败、HTTP响应不符、目标单点失败、断网中旧结果作废、关闭自动检查和灯关闭持久性；吞吐只做必要对照。
