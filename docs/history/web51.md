# web51：管理操作反馈收尾

2026-10-07。修复“点击重启后灯仍绿，以为未执行，再点一次”的管理体验；保留当前转发、无线、TCP窗口、NVS配置及串口命令。

## 修改与行为

- `main/management.html`：单独显示提交、接受、执行结果和重启等待；等待期间禁止重复变更，仍可手动刷新。HTTP拒绝与请求响应丢失分开处理，响应丢失不自动重发。旧状态回包不能结束新操作。
- `main/web_management.c`：状态新增随机启动标识 `boot_id`，维护响应带任务编号和是否需要重启。看到新的启动标识才确认重启；普通维护按任务编号匹配完成结果。
- `main/management_setup.html`：兼容请求助手同步HTTP错误分类，首次设置逻辑保持原行为。
- `tests/management_feedback_harness.js`、`tests/management_transport_harness.js`：覆盖等待、超时、重复点击、旧回包、丢失响应、浏览器兼容及网段变化。

通常10秒读取一次状态；等待操作时3秒。隐藏页面不自动读取。等待最多90秒，之后提示核对事件和配置，不自动重复提交。修改网段后显示新入口及旧地址回滚说明，不自动跨源访问。若90秒内仍未重连，请保存新地址并手动打开；配置试运行仍为180秒。

重连请求已执行不等于已恢复互联网；诊断任务完成不等于每项检查通过。页面明确区分这些含义。灯不用于证明重启发生。
