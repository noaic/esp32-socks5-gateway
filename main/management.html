Local AP and client network

The gateway and management address are 192.168.X.1. Changing this restarts the device; all clients must rejoin Wi-Fi, log in at the new address and confirm. The upstream and AP subnets must not overlap. If not confirmed, rejoin the restored subnet and reopen the old address.

Management security

Lengths are UTF-8 bytes: SSID up to 32, AP password 8–63, management password 12–64. Leave a password blank to keep it. A 64-byte upstream password must be a hexadecimal PSK; otherwise use 8–63 bytes. An empty upstream SSID starts only the AP. SOCKS5 supports IPv4 and NO AUTH only. DNS is forwarded through SOCKS5 UDP; this is not a local DNS service.

Restore default configuration

Restore the build-time Wi-Fi, default SOCKS5, DNS and two-client settings. Keep the current management password. Confirmation is required after restarting.

Connection diagnostics and Internet check

Use diagnostics to locate a failing stage. Tests send traffic through the configured proxy; they do not change or restart the network.



Diagnostics check only the configured upstream port, the NO AUTH handshake and an IPv4 DNS reply for example.com through SOCKS5 UDP. They do not probe a VPS directly or run periodically; success does not mean every website is reachable.


Internet check






All requests use the configured SOCKS5 service, with no direct fallback. Checks normally run every 5 minutes; failures back off for 30/60/120/240/300 seconds. Automatic checks require a ready upstream and confirmed network settings, and wait while maintenance is busy. Manual checks remain available when automatic checks are disabled. Green results expire after 10 minutes. Failures do not automatically restart the device or rebuild the proxy.

Connection maintenance


Reconnecting upstream interrupts proxy traffic but keeps the local AP. Rebuilding closes existing TCP/UDP proxy connections. Restarting closes all connections and retains configuration and password.




Management is available only on the AP. Log in as admin with the password you set on first access. RST/EN restarts without clearing it. Use a trusted personal device; HTTP does not provide transport encryption beyond Wi-Fi.
